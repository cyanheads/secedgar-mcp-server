# 0.17.1 — 2026-11-02

## Added

- **`filing_limit`** ([#212](https://github.com/cyanheads/secedgar-mcp-server/issues/212)) is accepted as an alias of `limit` on `secedgar_search_filings`, `secedgar_get_material_events`, and `secedgar_get_beneficial_owners`.

## Changed

- **`secedgar_compare_companies`** ([#201](https://github.com/cyanheads/secedgar-mcp-server/issues/201)) answers an over-cap `companies` or `concepts` list up to its cap and names the rest in `deferred_companies` / `deferred_concepts`. Input `maxItems` is 100 each (10 and 8 with `EDGAR_CLAMP_OVERSIZED_LIMITS=false`). With both lists deferred, the notice names three numbered re-calls that read the unread cells once each.
- **`secedgar_get_beneficial_owners`** ([#200](https://github.com/cyanheads/secedgar-mcp-server/issues/200)) keeps filer text line breaks, bounds Item 4 at 5,000 and notes at 2,000 characters, and discloses every cut. `reporting_persons[].notes_truncated` is always present.
- **Company name resolution** ([#210](https://github.com/cyanheads/secedgar-mcp-server/issues/210)) matches registry titles that differ only by commas, periods, and apostrophes, in four tiers ("QXO Inc" finds "QXO, Inc."). A former name typed as listed that now also matches a current registrant returns `multiple_matches`, current one first.
- **Biome** skips SEC's captured HTML fixtures (`tests/fixtures/**/*.html`) in lint and format.

## Fixed

- **EDGAR full-text search 200 bodies** ([#206](https://github.com/cyanheads/secedgar-mcp-server/issues/206)) carrying a transient backend error are retried; a backend failure or refusal surfaces as `efts_degraded_response`.
- **Full-text search escaping** ([#205](https://github.com/cyanheads/secedgar-mcp-server/issues/205)): each backslash is doubled and each control character written `\uXXXX`, so a query or entity name holding either is searched as typed instead of failing with HTTP 400. `secedgar_find_holders` searches the conformed name minus one trailing state/form qualifier.
- **Relevance `offset`** ([#214](https://github.com/cyanheads/secedgar-mcp-server/issues/214)) past 9,900 on `secedgar_search_filings` fails as `offset_out_of_range` before any request, where it read as an EDGAR outage.
- **`secedgar_fetch_frames` `no_data`** ([#207](https://github.com/cyanheads/secedgar-mcp-server/issues/207)) names the alternate tags it did not query (`unqueried_tags`), with no misleading start year.
- **`secedgar_get_filing` without `cik`** ([#203](https://github.com/cyanheads/secedgar-mcp-server/issues/203), [#215](https://github.com/cyanheads/secedgar-mcp-server/issues/215)) finds an agent-filed pre-2001 filing's filer through the filing index page, and a failed full-text-search filer lookup falls through to the accession-prefix CIK instead of failing the call.
- **`secedgar_get_filing` 2000–2001 documents** ([#213](https://github.com/cyanheads/secedgar-mcp-server/issues/213)): a sequence-numbered document is read under its accession-prefixed name. When that prefixed read of the primary hits a transient SEC failure, the call falls back to the full submission.
- **`secedgar_get_filing` structured XML forms** ([#216](https://github.com/cyanheads/secedgar-mcp-server/issues/216)) (13D/13G, Form 4, …) are read through SEC's rendering, with headings, and the filer's paragraph breaks are kept. `primary_document` names the path read, which can be a file `documents` does not list (the rendering, or `<accession>-<name>`).
- **`secedgar_compare_companies`** ([#217](https://github.com/cyanheads/secedgar-mcp-server/issues/217)) reads a company named twice (ticker and CIK) once, with a caveat.
- **`secedgar_find_holders` and `secedgar_company_search` notices** ([#220](https://github.com/cyanheads/secedgar-mcp-server/issues/220)) write their JSON calls as code spans, so a Markdown client keeps their backslashes.
