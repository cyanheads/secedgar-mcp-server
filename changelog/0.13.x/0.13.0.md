# 0.13.0 — 2026-07-26

## Added

- **`secedgar_get_snapshot`** — one-call financial profile. Reads the filer's whole companyfacts payload once and resolves every concept in the catalog against it, instead of one upstream request per concept. Duration concepts report their latest full year and latest single quarter (`period_type`: `annual` | `quarterly` | `both`); balance-sheet and entity-info concepts report their latest point-in-time value. Concepts the filer does not report land in `gaps` with `tags_tried` — never zero-filled. Declared errors: `company_not_found`, `ambiguous_company`, `no_company_facts`. ([#84](https://github.com/cyanheads/secedgar-mcp-server/issues/84))
- **`secedgar_compare_companies`** — period-aligned comparison of 2-10 companies across 1-8 concepts, one companyfacts read per company. Instant frames key on the calendar year (annual) or quarter (quarterly) they fall in, so balance-sheet lines sit in the same matrix as income-statement lines while each cell keeps its underlying `frame`. The inline matrix covers up to `periods` (1-12, default 4) and shrinks further at a 120-cell ceiling, disclosed through the `truncated` enrichment; the full aligned series is always registered as `df_<id>`. A company that fails to resolve is reported in `failed_companies` with a `not_found` / `ambiguous` / `no_company_facts` reason and the comparison proceeds with the rest. ([#85](https://github.com/cyanheads/secedgar-mcp-server/issues/85))
- **`concept-series.ts`** — `resolveFrameSeries` (frame dedup by tag priority, then latest `filed`), `matchesPeriodType`, and `seriesFromCompanyFacts` for whole-company reads. Every tool reading XBRL facts resolves through it, so their numbers agree.
- **`fiscal-periods.ts`** — `fiscalQ4Caveats(period)` for the cross-company frame view and `missingQuarterCaveats(frames)` for the per-filer series view.
- **`resolveConceptTarget(input, requestedTaxonomy)`** in `concept-map.ts` — returns the label, tag list, taxonomy, and unit to query. A mapping's own taxonomy wins over the `us-gaap` default; `ifrs-full` uses `ifrsTags` when present; unknown input passes through as a raw tag.
- **`EdgarMirror.getCompanyFacts(cik)`** — reassembles one filer's whole fact set in companyfacts API shape from its `(cik, taxonomy, tag)` rows, through a new `cik` index created idempotently on open. `tryGetCompanyFacts` routes to it behind `companyFactsReady()` with the live API as the fallback, so `get_snapshot` and `compare_companies` serve from the mirror when it is enabled and synced.
- **`tests/scripts/bundle-entry-patterns.test.ts`** — asserts `scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts` declare identical `AGENT_DOC_ENTRY` and `NATIVE_BINDING_ENTRY` patterns. A narrower linter pattern would pass a bundle that still ships the entries; a wider one would fail every bundle.

## Changed

- **`secedgar_get_financials` rebuilt on the shared modules** — the inline dedup, tag-priority collision resolution, period filter, and taxonomy/tag resolution now come from `concept-series.ts` and `resolveConceptTarget`. Output is unchanged apart from the new `caveats` field.
- **`CompanyFactsResponse` and `CompanyFactsConcept`** in `types.ts` — `tryGetCompanyFacts` returns them instead of `{ facts: Record<string, Record<string, unknown>> }`, and the mirror ingester's `CompanyFactsFile` is now `Partial<CompanyFactsResponse>`.
- **Server instructions** name `secedgar_get_snapshot` and `secedgar_compare_companies` alongside the existing financials tools.
- **`changelog/template.md`** — the tag-annotation reference is reconciled to `skills/git-wrapup/SKILL.md` v1.8: headline digest, flat bullets only, one deps line, no gates line, changelog link last.

## Fixed

- **`secedgar_get_financials` quarterly gap is now named** — a filer whose fiscal Q4 is reported as the 10-K residual has no frame-tagged value for the calendar quarter that fiscal Q4 spans, and the series returned it as a silent hole. Quarterly and `all` results now carry a `caveats` entry naming the absent quarter and how to recover it. Detection reads the frames themselves — no maintained filer list — over the newest 4 years carrying quarterly frames, requiring at least 3 reported quarters in a year for it to count and at least 2 counting years to agree on the same missing quarter. Calendar-year filers are affected as much as off-calendar ones. ([#95](https://github.com/cyanheads/secedgar-mcp-server/issues/95))
- **`secedgar_fetch_frames` fiscal-Q4 examples grouped by frame span** — the table keyed filers by the calendar quarter their fiscal year closes in, which put January year-ends under Q1. A January year-end closes a fiscal Q4 running Nov–Jan, which SEC frames as calendar Q4. Q1 is now `SJM Apr-end, and other Feb-to-Apr year ends`, Q4 gains `WMT/TGT Jan-end`, and the caveat reads "spans calendar Q*n*" rather than "closes in". ([#97](https://github.com/cyanheads/secedgar-mcp-server/issues/97))
