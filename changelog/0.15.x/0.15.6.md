# 0.15.6 — 2026-09-16

## Added

- **`createApp({ teardown })` closes the EDGAR mirror's SQLite handles on shutdown** ([cyanheads/mcp-ts-core#435](https://github.com/cyanheads/mcp-ts-core/issues/435)) — `EdgarMirror.close()` existed but nothing called it.
- **The Server Card publishes the resolved session mode** under the `_meta` key `io.github.cyanheads.mcp-ts-core/sessionMode` ([cyanheads/mcp-ts-core#387](https://github.com/cyanheads/mcp-ts-core/issues/387)) — `stateless` or `stateful`, never `auto`.

## Changed

- **`MCP_SESSION_MODE` unset now resolves `stateless`** from `createApp({ sessionMode })` ([cyanheads/mcp-ts-core#376](https://github.com/cyanheads/mcp-ts-core/issues/376)) — previously fell through the schema default `auto` to `stateful`; an exported `MCP_SESSION_MODE` still overrides. The Docker image and `.env.example` already set `stateless`, so a container deployment is unchanged.
- **`SIGTERM`/`SIGINT` now end the process explicitly** ([cyanheads/mcp-ts-core#435](https://github.com/cyanheads/mcp-ts-core/issues/435)) — exit `0` once shutdown settles, `1` when the 10s ceiling fires.
- **The framework skill tree moved from `skills/` to `framework-skills/`** ([cyanheads/mcp-ts-core#428](https://github.com/cyanheads/mcp-ts-core/issues/428)) — installing the Claude Code or Codex plugin no longer loads the server's development skills into the agent.
- **README restructured** — a new `## Overview` section replaces the bare `## Tools` opener, and every tool, resource, and prompt now has its own `### <name> <sub>tool|resource|prompt</sub>` entry under one `## Capability reference` section rather than separate `## Resources`/`## Prompts` sections.
- **Issue templates** — bug and feature forms auto-assign `cyanheads` and add secondary-label guidance (`regression`, `performance`, `security`, `breaking-change`, `surplus-token-idea`); `config.yml` allows blank issues and links a private security-advisory form.
- `bun run audit:fix` added (`bun audit fix`) — the first move when `devcheck` flags an advisory; the npm tarball's `files` also now ships `changelog/`, `CLAUDE.md`, and `AGENTS.md`.
- `.env.example` documents `MCP_HTTP_HOST`'s default as `127.0.0.1` (previously said `localhost`).

## Fixed

- **An empty `EDGAR_USER_AGENT=` or a whole-value unsubstituted `${…}` placeholder now reads as unset** ([cyanheads/mcp-ts-core#427](https://github.com/cyanheads/mcp-ts-core/issues/427)) — startup fails naming the missing variable instead of running with a blank `User-Agent` header.
- **`.claude-plugin/plugin.json` now delivers `EDGAR_USER_AGENT`** — declares `userConfig.EDGAR_USER_AGENT` (required) and passes `${user_config.EDGAR_USER_AGENT}`; it previously had no `userConfig`, so Claude Code couldn't prompt for the value and only an already-exported variable reached the server.
- **`.codex-plugin/mcp.json` now lists `EDGAR_USER_AGENT` in `env_vars`** — Codex's whitelisted child environment never delivered it before; `.codex-plugin/plugin.json`'s `interface.category` is now `finance` (was empty).

## Security

- **`secedgar_dataframe_query` SQL now passes through a linear-time comment stripper** ([cyanheads/mcp-ts-core#431](https://github.com/cyanheads/mcp-ts-core/issues/431)) — the framework canvas gate's comment stripper was a polynomial-time regex; a crafted statement up to the 1 MiB request-body cap could pin the event loop for minutes.
