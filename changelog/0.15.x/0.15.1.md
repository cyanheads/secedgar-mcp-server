# 0.15.1 — 2026-08-22

## Added

- **`truncated` / `shown` / `cap` enrichment** on `secedgar_get_filing`, `secedgar_company_search`, and `secedgar_dataframe_query` — a client reading only enrichment now sees that an inline result was capped and by which limit. `secedgar_dataframe_query`'s `cap` names whichever of `preview` or `row_limit` actually bound, and its guidance points at that lever.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`** — contribution workflow and the Contributor Covenant.

## Changed

- **Tool inputs are strict.** An argument key a tool does not declare is rejected by name before the handler runs rather than silently dropped, and each advertised `inputSchema` now carries `additionalProperties: false`. No tool here needed an explicit escape hatch. Inherited from the framework.
- **`.env.example` sets `MCP_SESSION_MODE=stateless`** as an active default rather than a commented-out `stateful` ([#108](https://github.com/cyanheads/secedgar-mcp-server/issues/108)). An HTTP consumer running from a copied `.env.example` no longer receives an `Mcp-Session-Id` on `initialize`; the published container already set the variable, so it and the hosted deployment are unchanged.
- **`secedgar_get_insider_transactions`** — rendered text carries one direction legend instead of repeating the `acquire`/`dispose` enum on every row.
- **`secedgar_get_filing`'s `outline`** — the description states the 50-heading ceiling `detectHeadings` already applied.
- **Security contact is `security@caseyjhand.com`** in `.github/SECURITY.md`.
- **Docker builds on Bun 1.4.0**, with the build stage pinned to `$BUILDPLATFORM` — Bun's JavaScriptCore aborts under QEMU, so a cross-arch build of that stage failed outright. The OTel install passes `--omit=peer`.
- **`tsconfig.json` typechecks `tests/` alongside `src/`** under `noEmit`; emission moves to `tsconfig.build.json`, which keeps `rootDir: src`. `tests/support/assertions.ts` holds the narrowing helpers the suite needs under `noUncheckedIndexedAccess`.
- **`bundle` invokes `npx`** instead of `bunx`, and `packageManager` is `bun@1.4.0`.

## Fixed

- **`bun run tree` honors directory-only `.gitignore` patterns.** `isIgnored` takes the entry's `Dirent` flag and tests `<path>/` for a directory, which is the only form a pattern like `/data/` matches.
