# 0.15.11 — 2026-10-04

## Changed

- **`secedgar_search_filings` counts filings, not matching documents** — one row per accession, each full-text row listing its `matched_documents`; `total` and `form_distribution` count filings, exact for a forms- or entity-only browse and a lower bound beside the new `total_documents` for a search with terms ([#124](https://github.com/cyanheads/secedgar-mcp-server/issues/124)).
- **`sort=relevance` pages** — `offset` counts matching documents, so a page lists the filings among its own `limit` documents and can hold fewer than `limit` rows; a filing whose documents straddle a page edge recurs on the next page ([#124](https://github.com/cyanheads/secedgar-mcp-server/issues/124)).
- **`secedgar_get_filing` `primary_document` is the form-typed document SEC records**, not the largest file — an 8-K reads the form rather than a press-release exhibit, and a 13F-HR reports its cover page `primary_doc.xml` (holdings are unaffected) ([#161](https://github.com/cyanheads/secedgar-mcp-server/issues/161)).
- **XBRL series read one unit** — a 20-F filer's USD convenience translation no longer splices into its reporting-currency series; `secedgar_get_financials` takes a new `unit` input and fails as `no_unit_data`, listing the reported units, for one the concept lacks ([#146](https://github.com/cyanheads/secedgar-mcp-server/issues/146)).
- **Company-identifier aliases** — `secedgar_company_search` `query` accepts `company`, `ticker`, `cik`, `ticker_or_cik`, `name`, and `search`; the `issuer` of `secedgar_find_holders` and `secedgar_get_beneficial_owners` accepts `company`, `ticker`, `cik`, and `ticker_or_cik` ([#152](https://github.com/cyanheads/secedgar-mcp-server/issues/152)).
- **Plain-text filings keep their line structure** — legacy SGML bodies convert with their lines, so they get an outline and `section` lands, and text offsets in them shift; a `section` ending in a number no longer matches a longer one (`item 1` never lands on Item 12) ([#136](https://github.com/cyanheads/secedgar-mcp-server/issues/136)).
- **Full-submission `.txt` text** — a submission holding an HTML document now includes its plain-text exhibits in document order ([#159](https://github.com/cyanheads/secedgar-mcp-server/issues/159)) and drops the EDGAR renderer's XBRL viewer pages (`R1.htm`…) ([#160](https://github.com/cyanheads/secedgar-mcp-server/issues/160)).
- **Truncated dataframe pointer** — when `dataset.truncated` is true the pointer says the rows fetched are staged, not the full set ([#162](https://github.com/cyanheads/secedgar-mcp-server/issues/162)).
- **Output-schema descriptions trimmed** across the tools, shrinking the `outputSchema` text `tools/list` advertises; a test bounds it to 40 KB total and 300 bytes per description ([#131](https://github.com/cyanheads/secedgar-mcp-server/issues/131)).

## Fixed

- **Company-name resolution** — an exact or suffix-dropped name hit (`Apple` → Apple Inc.) resolves without listing weaker prefix or substring hits beside it, and a former name never outranks a current one ([#155](https://github.com/cyanheads/secedgar-mcp-server/issues/155)).
- **`secedgar_company_search` `no_match`** points at `data.suggestions` only when the error carries them ([#153](https://github.com/cyanheads/secedgar-mcp-server/issues/153)).
- **Archive reads use the unpadded CIK** — each read, and `secedgar_get_filing`'s `filing_url`, skips SEC's 301 from the zero-padded path, so it costs one request instead of two ([#156](https://github.com/cyanheads/secedgar-mcp-server/issues/156)).
- **`interest_expense`** walks `InterestExpenseOperating` last, so banks reporting interest expense only under it (JPMorgan, Bank of America, Wells Fargo from 2024) return current values ([#147](https://github.com/cyanheads/secedgar-mcp-server/issues/147)).
- **10-Q-held annual frames** that their own tag and unit cannot test are checked against the filer's fiscal-year ends from its annual reports, so a trailing-twelve-month figure drops out of the annual series ([#148](https://github.com/cyanheads/secedgar-mcp-server/issues/148)).
- **`secedgar_get_material_events`** — an undated `items`-filtered call walks the archive until `limit` filings pass the filter, and a short result names how far the scan reached and the `filed_before` that goes further ([#139](https://github.com/cyanheads/secedgar-mcp-server/issues/139)).
- **`secedgar_get_insider_transactions`** — Form 4s the company filed as a reporting owner of another issuer add no rows, inline or in the dataframe, and are counted in the new `filings_other_issuer` ([#157](https://github.com/cyanheads/secedgar-mcp-server/issues/157)).
- **`secedgar_get_filing` on 2000–2001 filings** whose index names a primary document the archive does not serve reads the full submission `<accession>.txt` instead of failing, and the notice names the unserved file ([#158](https://github.com/cyanheads/secedgar-mcp-server/issues/158)).
