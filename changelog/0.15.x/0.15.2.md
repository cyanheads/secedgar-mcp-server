# 0.15.2 — 2026-09-02

Framework adoption and dependency updates — this server's own source is unchanged.

## Changed

- **An SEC 5xx surfaces as `ServiceUnavailable` instead of `InternalError`.** `EdgarApiService` classifies every non-OK SEC response through the framework's `httpErrorFromResponse`, which no longer maps 500 or 501 to a code asserting that this server failed. A client branching on `InternalError` for an upstream EDGAR outage must move to `ServiceUnavailable`.
- **A caller that disconnects mid-call classifies as `RequestCancelled` (-32011)** rather than `InternalError` or `Timeout`. It is a baseline code, so no tool declares it and it is never retried.

## Fixed

- **Server identity resolves from the served package, not the launching client's working directory.** `createApp` declares only `name` and `title` here, so the advertised version, description, and keywords are read from this package's `package.json` on every launch path (`npx`, `.mcpb`, a client config naming `dist/index.js`).
- **Records logged from `setup()` are no longer dropped** — the EDGAR mirror's refresh-scheduling messages (`EDGAR_MIRROR_REFRESH_CRON` under the HTTP transport) are buffered and replayed once the logger initializes.
- **The README's MCP SDK badge reads `^2.0.0`**, matching the `@modelcontextprotocol/server` range the framework depends on; it had been left at `^1.29.0`.
