# 0.15.8 — 2026-09-24

## Added

- **`secedgar_get_insider_transactions` `filed_after` / `filed_before`** ([#127](https://github.com/cyanheads/secedgar-mcp-server/issues/127)) — inclusive, either alone, with the `start_date` / `date_from` / `end_date` / `date_to` aliases. A window reads the in-window Form 4 / 4-A filings from the recent window and the archive pages it overlaps, parsing up to 100 with a canvas; `history_scanned_through` names the oldest filing parsed, and a window holding none returns a notice rather than `no_filings_found`.

## Changed

- **`secedgar_get_filing` fills `form`, `filing_date`, and `period_ending` for filings outside the recent submissions window** ([#126](https://github.com/cyanheads/secedgar-mcp-server/issues/126)) — read from the filing's own SEC header: the `index-headers.html` page the tool already fetches, or `<accession>.hdr.sgml` when that page is missing (one extra request, only then).
- **One archive-page walk for every tool that reads past the recent window** — `SubmissionsArchiveWalk` (`src/services/edgar/submissions-archive.ts`) serves `secedgar_company_search`, `secedgar_search_filings`' pre-2001 arm, `secedgar_get_material_events`, `secedgar_get_insider_transactions`, and `secedgar_get_institutional_holdings`, with one 10-page cap.
- Tool descriptions state the recent window as SEC sizes it — the last year or 1,000 filings, whichever holds more — instead of "~1,000 filings".

## Fixed

- **`secedgar_get_institutional_holdings` finds a `quarter` older than the recent window** ([#117](https://github.com/cyanheads/secedgar-mcp-server/issues/117)) — the archive is read forward from the quarter end, up to 10 pages, instead of failing as `no_filings_found`.
- **A quarter covered by a 13F-NT notice fails naming that notice** ([#133](https://github.com/cyanheads/secedgar-mcp-server/issues/133)) — the error carries its accession number, form, and period (`notice_accession_number`, `notice_form`, `notice_period`); a manager with no `quarter` whose recent 13F filings are all notices gets the same message instead of the not-a-13F-filer routing.
- **`filer_name` decodes XML entities** ([#132](https://github.com/cyanheads/secedgar-mcp-server/issues/132)) — `JPMORGAN CHASE &amp; CO` is now `JPMORGAN CHASE & CO` on every surface.
- **A failed load of `company_tickers_mf.json` no longer stands for the whole ticker-cache TTL** ([#119](https://github.com/cyanheads/secedgar-mcp-server/issues/119)) — the fund slice is refetched once, single-flight, after 60 s (or the rate-limit cool-down, if longer), without refetching the equity index; each failed load logs a warning.
- **Fund tickers keep `seriesId` / `classId` on the mirror path** ([#135](https://github.com/cyanheads/secedgar-mcp-server/issues/135)) — a live fund entry supersedes the mirror's bare fund row for the same symbol, and mirror fund rows never enter the CIK index, so `secedgar_get_fund_holdings` routes a multi-series trust's ticker through its series.
- **`rate_limited` errors carry `data.retryable: true`** ([#122](https://github.com/cyanheads/secedgar-mcp-server/issues/122)) — both the upstream 429 and the local cool-down refusal, matching the declared contract, so the text ends `(reason rate_limited · retryable)`.
- **Deeply nested markup no longer overflows the stack in filing text conversion** ([#118](https://github.com/cyanheads/secedgar-mcp-server/issues/118)) — `html-to-text` stops at 512 levels and prints `[…]` there, and legacy SGML `<PAGE>` markers are replaced with line breaks before parsing; one such document no longer fails `secedgar_search_filings`' pre-2001 text scan.
- **`secedgar_get_material_events` stops the undated archive walk once `limit` is filled** ([#134](https://github.com/cyanheads/secedgar-mcp-server/issues/134)) — it previously read every page up to the cap; `dataset.truncated` is true whenever selected pages went unread.
- **Archive page selection tolerates a one-day drift in the manifest's `filingFrom` / `filingTo`** ([#137](https://github.com/cyanheads/secedgar-mcp-server/issues/137)) — a window starting on a page's newest filing day no longer skips that page.
- **`secedgar_dataframe_query` renders a line break inside a table cell or column name as `<br>`** ([#121](https://github.com/cyanheads/secedgar-mcp-server/issues/121)) — it previously split the Markdown row.
