# 0.15.3 — 2026-09-09

## Fixed

- **`secedgar_company_search` name matching now normalizes the terminal corporate-suffix token** (`Beacon Financial Corporation` matches registry entry `Beacon Financial Corp`), while keeping `Corp`, `Inc`, `Co`, and `Ltd` as four separate buckets so real registrants differing only by suffix (`TORO CO` vs `TORO CORP.`) stay distinct ([#107](https://github.com/cyanheads/secedgar-mcp-server/issues/107)).
- **Dotted share-class tickers (`BRK.B`) now resolve** via SEC's hyphenated form (`BRK-B`) in `secedgar_company_search` and `secedgar_search_filings`'s `ticker:` targeting ([#110](https://github.com/cyanheads/secedgar-mcp-server/issues/110)).
- **A zero-hit ticker query now returns near-ticker suggestions** (`CSWI` → `CSW`), scored alongside name suggestions in one ranked list; the `no_match` recovery message is unified for both ticker- and name-shaped misses ([#111](https://github.com/cyanheads/secedgar-mcp-server/issues/111)).
- **A 429 from SEC no longer retries into its ten-minute rate-limit block.** `EdgarApiService` fails fast on the first 429 with a `recovery` hint naming the cool-down, and SEC's raw HTML block page is no longer captured into `data.body` ([#112](https://github.com/cyanheads/secedgar-mcp-server/issues/112)).
