# 0.15.9 — 2026-09-25

## Added

- **Catalog concepts `ppe_net`, `pretax_income`, and `shares_diluted`** ([#130](https://github.com/cyanheads/secedgar-mcp-server/issues/130)) — each with a confirmed IFRS tag; `ppe_net` lists the finance-lease-inclusive total as a related tag, not a fallback.
- **`unknown_concept` before any SEC request** ([#128](https://github.com/cyanheads/secedgar-mcp-server/issues/128)) — `secedgar_get_financials`, `secedgar_compare_companies`, and `secedgar_fetch_frames` reject a `concept` that is neither a friendly name nor an UpperCamelCase tag, with a formula (`free_cash_flow`, `ebitda`, `working_capital`) or up to three closest names. `secedgar_compare_companies` fails only when every concept is unknown and otherwise lists them in `unknown_concepts`.
- **`secedgar_fetch_frames` `taxonomy` input, `us-gaap` or `dei`** ([#143](https://github.com/cyanheads/secedgar-mcp-server/issues/143)) — a raw dei tag such as `EntityCommonStockSharesOutstanding` now reads the dei frames; the response echoes `taxonomy`.
- **Per-value `tag`** on `secedgar_get_financials` rows, `secedgar_get_snapshot` points, and `secedgar_compare_companies` cells ([#125](https://github.com/cyanheads/secedgar-mcp-server/issues/125)).

## Changed

- **`capex` walks `PaymentsToAcquireProductiveAssets` and `interest_expense` walks `InterestExpenseNonoperating`** ([#125](https://github.com/cyanheads/secedgar-mcp-server/issues/125)) — both behind the existing tags, so they fill only frames those leave empty. A line's `concept` / `tag`, `label`, and `unit` now describe the tag behind its newest value.
- **`secedgar_company_analysis` routes the financial profile through `secedgar_get_snapshot` and the peer step through `secedgar_compare_companies`** ([#129](https://github.com/cyanheads/secedgar-mcp-server/issues/129)); `secedgar://concepts` and `secedgar_search_concepts` name all three tools that take a friendly name.
- **`secedgar_compare_companies` compares inputs naming the same concept once** ([#145](https://github.com/cyanheads/secedgar-mcp-server/issues/145)) — `revenue` and `Revenue` merge under the first spelling with a caveat; a friendly name and a raw tag it maps to stay separate.

## Fixed

- **A frame held by a Schedule 14A/14C proxy statement resolves to the filer's own report of the period** ([#123](https://github.com/cyanheads/secedgar-mcp-server/issues/123)) — the pay-versus-performance `NetIncomeLoss` no longer replaces the 10-K value. Live `secedgar_fetch_frames` responses carry a caveat on annual `NetIncomeLoss`; mirror-served frames apply the rule.
- **An annual frame held by a 10-Q's trailing-twelve-month figure leaves the annual series** ([#142](https://github.com/cyanheads/secedgar-mcp-server/issues/142)) — replaced by the 10-K fact when one exists, else kept only when the series marks it a closed fiscal year. Live `secedgar_fetch_frames` caveats annual frames through April of the following year.
- **A companyconcept unit served as an empty object no longer fails `secedgar_get_financials`** ([#141](https://github.com/cyanheads/secedgar-mcp-server/issues/141)) — non-array units are dropped at the service edge and the tag is answered from companyfacts.
- **`secedgar_compare_companies` names a company whose values all predate the inline window** ([#144](https://github.com/cyanheads/secedgar-mcp-server/issues/144)) — one caveat per concept with each company's newest period; `gaps` still means no value in any period.
- **Mirror reads no longer print a raw tag as its label** when SEC served none (`InterestExpenseNonoperating`), and `secedgar_fetch_frames` treats SEC's bare `-` `loc` as no location.
