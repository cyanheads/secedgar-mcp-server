# 0.15.14 — 2026-10-23

## Changed

- **Every SEC-reaching tool honors `ctx.signal` and a 40 s per-call failure budget** ([#179](https://github.com/cyanheads/secedgar-mcp-server/issues/179)). A cancel removes the call's queued requests from the pacer and aborts the request, body read, or backoff in flight, settling as `RequestCancelled`. A call whose SEC failures (unanswered attempts, backoff, body stalls) sum past 40 s stops: `sec_unreachable`, or the 5xx mapping when the last answer was a 5xx, where it previously kept retrying. Healthy time never counts against the budget.
- **SEC response bodies are read inside the retry ladder** ([#181](https://github.com/cyanheads/secedgar-mcp-server/issues/181)). A body that breaks off, or sends no bytes for 15 s, is retried like a no-response attempt and, exhausted, fails as `sec_unreachable`; a 200 that is not JSON fails the same way, unretried. The `sec_unreachable` `when` and `recovery` text on the 13 SEC-reaching tools now cover an incomplete or unreadable response.
- **`secedgar_search_filings` `filed_after` / `filed_before`** work alone ([#185](https://github.com/cyanheads/secedgar-mcp-server/issues/185)). A lone `filed_after` runs through today (UTC); a lone `filed_before` starts at 2001-01-01, or at 1993-01-01 when it is earlier. The full-text `effectiveQuery` ends ` (filed <after> to <before>)` when a bound was filled, and a capped pre-2001 full-index browse names the quarters it read. The `pre2001_full_text_unscoped` hint offers starting the range at 2001-01-01 only when the range reaches that date.
- **`secedgar_dataframe_query`, `secedgar_dataframe_describe`, `secedgar_dataframe_drop`** `canvas_unavailable` recovery text names the MCPB bundle, which ships no DuckDB native binding.

## Removed

- **`invalid_date_range`** error reason on `secedgar_search_filings`; a lone date bound is filled instead of rejected.

## Fixed

- **`secedgar_get_filing` heading detection** finds an Item or Part marker whose title abuts it: `Item 2.Management…`, `Item 1A.Risk Factors`, `Item 1Financial Statements`, `Part IFinancial Information` ([#180](https://github.com/cyanheads/secedgar-mcp-server/issues/180)).
- **`secedgar_get_filing` `section`** lands on a body heading ahead of a table-of-contents row whose title wraps onto a second line with its page number below ([#183](https://github.com/cyanheads/secedgar-mcp-server/issues/183)).
- **`secedgar_get_filing` `section`** ranks a document line that labels a table row after every heading containing the value, so a one-word value such as `revenue` reaches the MD&A heading instead of a table row ([#184](https://github.com/cyanheads/secedgar-mcp-server/issues/184)).
- **An empty `CANVAS_PROVIDER_TYPE`** (environment or `.env`) selects the DuckDB default. The MCPB bundle sets `CANVAS_PROVIDER_TYPE=none`, so there the dataframe tools fail as `canvas_unavailable` with a hint naming the bundle.
