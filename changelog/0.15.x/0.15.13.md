# 0.15.13 — 2026-10-18

## Added

- **`sec_unreachable` error reason** (`ServiceUnavailable`, retryable) on the 13 tools that declare `rate_limited`. A SEC request that gets no HTTP response (refused, reset, DNS failure, or no response headers within 15 s) is retried on the existing three-attempt ladder and, exhausted, fails with it. Calls waiting behind a probe that gets no answer after a 429 cool-down count it as their own attempt ([#173](https://github.com/cyanheads/secedgar-mcp-server/issues/173)).

## Changed

- **`EDGAR_USER_AGENT`** a value `fetch` cannot send as a header (an em dash, an inner line break) stops the server at startup ([#173](https://github.com/cyanheads/secedgar-mcp-server/issues/173)).
- **`secedgar_get_filing` `section`** with a blank value fails `section_not_found` instead of landing on the first heading. A proxy statement keeps its previous heading order.
- **`secedgar_get_filing` paging footer** after a `section` landing says to drop `section` when passing `next_offset`, since `section` outranks `offset`.

## Fixed

- **`secedgar_get_filing` `section`** lands on a body heading ahead of a table-of-contents row ([#174](https://github.com/cyanheads/secedgar-mcp-server/issues/174)).
- **`secedgar_get_filing` `section`** ignores a leading 20-F sub-item label when matching ([#175](https://github.com/cyanheads/secedgar-mcp-server/issues/175)).
- **`secedgar_get_filing` 8-K Item headings** led by a non-breaking space are detected ([#176](https://github.com/cyanheads/secedgar-mcp-server/issues/176)).
- **`secedgar_get_filing` `section`** lands on a document line equal to the value ahead of a non-Item heading that merely contains it, and the notice says so ([#177](https://github.com/cyanheads/secedgar-mcp-server/issues/177)).

## Security

- **`secedgar_get_filing`** resolves a `section` value in time linear in its length.
