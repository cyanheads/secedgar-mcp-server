# 0.18.0 — 2026-11-03

## Changed

- **Breaking: calls that answered now fail, listing the matches** ([#218](https://github.com/cyanheads/secedgar-mcp-server/issues/218), [#219](https://github.com/cyanheads/secedgar-mcp-server/issues/219), [#223](https://github.com/cyanheads/secedgar-mcp-server/issues/223)). `secedgar_get_insider_transactions` with `company` "Energizer Holdings Inc" or "Blue Owl Capital" fails with `ambiguous_company`, and so does `secedgar_search_filings` with `ticker:Fluent`. `secedgar_company_search` with `query` "u s gold corp" or "baldw" fails with `multiple_matches`. Retry with a ticker or CIK from the list.
- **Company name resolution** ([#218](https://github.com/cyanheads/secedgar-mcp-server/issues/218), [#219](https://github.com/cyanheads/secedgar-mcp-server/issues/219)): no hit starts or ends inside a word ("SY Bancorp" no longer finds "Embassy Bancorp"), whitespace runs and spaced initials fold ("JM Smucker" finds "J M SMUCKER Co"), and a query with no letter or digit matches nothing. The `secedgar_company_search` `query` description follows.
- **`ambiguous_company`** ([#223](https://github.com/cyanheads/secedgar-mcp-server/issues/223)) is declared in `errors[]` on `secedgar_get_insider_transactions` and `secedgar_search_filings`, with the candidates in `data.matches` (`cik`, `name`, `ticker`) as on `secedgar_get_financials`.
- **USD amounts in `content[]`** ([#222](https://github.com/cyanheads/secedgar-mcp-server/issues/222)) scale by magnitude (T, B, M, K) with the sign before the `$` in `get_financials`, `fetch_frames`, `get_institutional_holdings`, and `get_fund_holdings`, so a small value no longer reads as `$0.00B` or `$0.0M`. Per-share and other-unit values keep every digit.
- **SEC and caller text in `content[]`** ([#221](https://github.com/cyanheads/secedgar-mcp-server/issues/221)), such as names, labels, descriptions, echoed inputs, and dataframe cells, is Markdown-escaped so a CommonMark parse reads back the `structuredContent` value; `secedgar_dataframe_describe` prints staged parameters as code spans. Escaping runs in time linear in input length ([mcp-ts-core#809](https://github.com/cyanheads/mcp-ts-core/issues/809)).
- **`secedgar_find_holders`** ([#224](https://github.com/cyanheads/secedgar-mcp-server/issues/224)) adds a notice when another current registrant's name reduces to the searched phrase (`FIRST BANCORP /PR/` and `/NC/`), naming it with CIK and ticker and pointing to `cusip`.
