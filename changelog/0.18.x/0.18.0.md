# 0.18.0 — 2026-11-03

## Changed

- **Breaking: calls that answered now fail or return several matches** ([#218](https://github.com/cyanheads/secedgar-mcp-server/issues/218), [#219](https://github.com/cyanheads/secedgar-mcp-server/issues/219), [#223](https://github.com/cyanheads/secedgar-mcp-server/issues/223)). `secedgar_get_insider_transactions` with `company` "Energizer Holdings Inc" or "Blue Owl Capital" fails with `ambiguous_company`, listing the matches. `secedgar_search_filings` with `ticker:Fluent` fails the same way. `secedgar_company_search` with `query` "u s gold corp" or "baldw" returns `multiple_matches`. Retry with a ticker or CIK from the list.
- **Company name resolution** ([#218](https://github.com/cyanheads/secedgar-mcp-server/issues/218), [#219](https://github.com/cyanheads/secedgar-mcp-server/issues/219)): no hit starts or ends inside a word ("SY Bancorp" no longer finds "Embassy Bancorp"), whitespace runs and spaced initials fold ("JM Smucker" finds "J M SMUCKER Co"), and a query with no letter or digit matches nothing. The `secedgar_company_search` `query` description follows.
- **`secedgar_get_insider_transactions` and `secedgar_search_filings`** ([#223](https://github.com/cyanheads/secedgar-mcp-server/issues/223)) declare `ambiguous_company` in `errors[]`; `get_financials` and `get_snapshot` share the candidate list through the `ambiguousMatches` helper.
- **USD amounts in `content[]`** ([#222](https://github.com/cyanheads/secedgar-mcp-server/issues/222)) scale by magnitude (T, B, M, K) with the sign before the `$`, so a small value no longer reads as `$0.00B` or `$0.0M`. Applies to `get_financials`, `fetch_frames`, `get_institutional_holdings`, and `get_fund_holdings`.
- **SEC and caller strings in `content[]`** ([#221](https://github.com/cyanheads/secedgar-mcp-server/issues/221)) render through the new `escapeInline` helper, so a CommonMark parse reads back the `structuredContent` value. Covers the tool `format()`s and the dataframe tools' parameters, columns, cells, and names. Markdown escaping in `content[]` runs in time linear in its input length (mcp-ts-core#809).
- **`secedgar_find_holders`** ([#224](https://github.com/cyanheads/secedgar-mcp-server/issues/224)) adds a notice when another current registrant's name reduces to the searched phrase (`FIRST BANCORP /PR/` and `/NC/`), naming it with CIK and ticker and pointing to `cusip`.
